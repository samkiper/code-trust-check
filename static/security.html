Security

Designed to review code without running it.

AI Code Audit separates static review from execution and minimizes retained source data.

Current protections

  • Submitted code is not executed by the web service.
  • Local analysis uses temporary files that are removed after scanning.
  • GitHub webhook payloads are authenticated with the configured webhook secret.
  • GitHub App access uses installation-scoped tokens and narrow repository permissions.
  • Account and repository records are server-controlled with database row-level security.
  • Rate limits protect public and authenticated endpoints.
  • Security headers restrict framing, content types, browser permissions, and resource origins.

Report a vulnerability

Use the repository’s private GitHub Security Advisory form or email support.aicodeaudit@gmail.com. Do not open a public issue containing an exploit, credential, private repository name, customer information, or other sensitive material.

Scope

Reports about the hosted application, authentication, billing integration, GitHub App, repository access, scanner isolation, or unintended data exposure are useful. Scanner false positives and missed-risk examples belong in the ordinary support process unless they reveal a vulnerability in the service itself.
