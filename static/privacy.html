Privacy

Minimal data by design.

Last updated September 7, 2026. This page explains what AI Code Audit processes, what it retains, and which service providers are involved.

Manual code and public-repository audits

Submitted code is processed to produce the requested audit. It is not executed and AI Code Audit does not retain a raw source-code copy after the request completes. Temporary files used by local analysis are deleted after scanning.

Accounts and authentication

If you create an account, the service processes your email address, account identifier, authentication session, plan status, and limited billing identifiers. Authentication and account records are handled through Supabase.

GitHub App data

When you connect the GitHub App, AI Code Audit stores installation and repository identifiers needed to provide pull-request checks. Scan history stores repository and pull-request metadata, counts, fingerprints, and sanitized finding explanations. It does not store a raw source-code copy.

Feedback and reviewed findings

Feedback and suppression records may include a user identifier, scan and finding fingerprints, category, disposition, reason, timestamps, and optional expiration. These records support review history and scanner improvement without retaining submitted source code.

Billing

Stripe processes checkout and payment details. AI Code Audit stores limited Stripe customer, subscription, and status identifiers needed to activate and manage Pro access. AI Code Audit does not receive or store full card numbers.

Operational data

The hosting platform and service may process ordinary request metadata, security events, rate-limit identifiers, and error information needed to operate and protect the service. Sensitive values are not intentionally included in public responses.

Retention

AI Code Audit does not currently promise a fixed automatic deletion schedule for account, installation, scan-history, feedback, suppression, or billing-status records. Those records are retained as needed to provide account features, security review, billing status, and auditability. Raw source-code copies are not retained as described above.

Service providers

  • GitHub for repositories, installations, and pull-request checks
  • Render for application hosting
  • Supabase for authentication and application records
  • Stripe for subscription billing
  • OSV for supported dependency-vulnerability lookups

Your choices

You may disconnect or uninstall the GitHub App through GitHub and manage or cancel a paid subscription through the account billing portal. For privacy questions or data requests, email support.aicodeaudit@gmail.com. Do not place private account information in a public GitHub issue.
