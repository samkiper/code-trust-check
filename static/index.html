What this audit can tell you

It statically reviews supported code for credential exposure, risky execution, unexpected network behavior, suspicious dependencies, and behavior that may conflict with your stated request.

What it cannot prove

  • Code is never executed, so runtime-only behavior may be missed.
  • A clean result is not a guarantee that code is safe.
  • Cross-file analysis and dependency coverage vary by language and project structure.
  • Use the findings as review evidence, not a replacement for testing or professional security review.
