# Changelog

## v20.1.0 — Launch-readiness update

- aligned website, verdict, badge, and GitHub score colors to one risk policy
- made the three-state verdict primary and renamed the displayed number to Audit Score
- clarified static-analysis claims, language coverage, and limitations
- expanded the Free and Pro comparison to reflect the features already built
- added public methodology, privacy, terms, security, and support pages
- added repository onboarding, security, contribution, and release documentation
- added search and social metadata, `robots.txt`, and `sitemap.xml`
- did not change detection rules, weights, or published accuracy measurements

## v20.0.0 — Policy and review workflows

- bounded Semgrep cold-start retries and engine telemetry
- opt-in per-repository severity policies
- accepted-risk, false-positive, and temporary suppressions
- scan-to-scan pull-request comparisons
- Beginner and Developer result views
- severity filtering and pagination
